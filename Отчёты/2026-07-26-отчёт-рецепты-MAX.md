# Отчёт: персональная книга рецептов в MAX

**Дата:** 2026-07-26

## Что сделано

Создала отдельного MAX-бота для персональной книги рецептов. Пользователь присылает ссылку — бот вытаскивает название, ингредиенты, фото, шаги и источник. Всё сохраняется в личную коллекцию.

## Функции первой версии

- 📚 **Мои рецепты** — пагинированный список с возможностью открыть карточку.
- ➕ **Добавить по ссылке** — автопарсинг рецептов с сайтов (schema.org + эвристики по заголовкам).
- ✍️ **Добавить вручную** — пошаговый ввод названия, ингредиентов, способа приготовления, порций, источника и фото.
- 🔍 **Поиск** — по названию или по ингредиенту.
- ✏️ **Редактировать** — любое поле рецепта.
- 🗑 **Удалить** — с подтверждением.
- 🛒 **Список покупок** — по отдельному рецепту в виде чек-листа.
- 🔗 **Ссылка на источник** — сохраняется и показывается в карточке.

## Что отложено

- Расчёт КБЖУ — решили сделать позже.
- Список покупок сразу по нескольким рецептам.

## Новые и изменённые файлы

- `src/bot/max-recipe/index.js` — главный файл MAX-бота книги рецептов.
- `src/bot/max-recipe/keyboards.js` — inline-клавиатуры.
- `src/bot/max-recipe/session.js` — состояния пользователя.
- `src/services/recipeParser.js` — парсинг рецептов с сайтов.
- `src/services/recipeService.js` — CRUD и поиск по рецептам.
- `src/db/index.js` — таблица `recipes` и индексы.
- `src/config/index.js` — добавлен `MAX_RECIPE_BOT_TOKEN`.
- `src/index.js` — запуск нового MAX-бота рядом с текущим.
- `.env.example` — пример токена нового бота.
- `package.json` / `package-lock.json` — добавлена библиотека `cheerio`.

## Проверка

- `node --check` прошёл для всех новых и изменённых файлов.
- Сервер запускается: `npm start` поднимает Telegram-бота, планировщик и оба MAX-бота (если заданы токены).
- Парсер протестирован на povar.ru: вытащил название, фото и ингредиенты.

## Что нужно для запуска

1. Создать нового бота в МАКС и получить токен.
2. Добавить в `.env`:
   ```env
   MAX_RECIPE_BOT_TOKEN=токен_нового_бота
   ```
3. Установить зависимости:
   ```bash
   npm install
   ```
4. Запустить:
   ```bash
   npm start
   ```
