# План: деплой Kniga на Beget

**Дата:** 2026-07-26

## Контекст

- Сервер Beget: `159.194.204.27`.
- Там уже работает основной бот `Konditer` через PM2 (`konditer-bot`) на порту 3000.
- Kniga должен работать рядом на другом порту (например, 3001).

## Цель

Развернуть `Kniga` на том же сервере Beget как отдельный PM2-процесс.

## Подготовка на сервере

1. Подключиться по SSH:
   ```bash
   ssh root@159.194.204.27
   ```

2. Перейти в папку проекта:
   ```bash
   cd /opt/konditer-bot
   ```

3. Обновить код из GitHub (если репозиторий используется) или скопировать папку `Kniga` вручную.

## Развёртывание Kniga

### Вариант A: Kniga внутри текущего репозитория

Если папка `Kniga` уже в репозитории `Konditer`, достаточно:

```bash
cd /opt/konditer-bot/Kniga
npm install
```

Создать `.env`:
```bash
nano .env
```

Содержимое:
```env
NODE_ENV=production
PORT=3001
MAX_RECIPE_BOT_TOKEN=токен_из_MAX
NODE_TLS_REJECT_UNAUTHORIZED=0
```

Запустить через PM2:
```bash
pm2 start src/index.js --name kniga-bot
pm2 save
```

### Вариант B: отдельный репозиторий или папка

Если хочешь полностью отдельный проект:

```bash
cd /opt
mkdir -p kniga-bot
cd kniga-bot
# скопировать файлы через scp / git clone
npm install
nano .env
pm2 start src/index.js --name kniga-bot
pm2 save
```

## Проверка

```bash
pm2 status
pm2 logs kniga-bot
```

Должно быть:
```text
MAX-бот рецептов запущен
Сервер запущен на порту 3001
```

## Важные моменты

- Порт 3001 должен быть открыт в фаерволе Beget, иначе healthcheck MAX не пройдёт.
- `NODE_TLS_REJECT_UNAUTHORIZED=0` оставляем, если на сервере та же проблема с SSL, что и на Windows.
- База SQLite будет создаваться в `Kniga/data/recipes.db`.
- PM2 запустит процесс автоматически после перезагрузки сервера, если `pm2 save` и `pm2 startup` уже выполнены ранее.

## Что проверить в МАКС

1. Найти бота по токену / имени в МАКС.
2. Отправить `/start` — появится меню.
3. Прислать ссылку на рецепт — бот распарсит и предложит сохранить.
4. Проверить «Мои рецепты», поиск, редактирование, список покупок.

## Следующие шаги после деплоя
