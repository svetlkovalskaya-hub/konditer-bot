# План: персональная книга рецептов в MAX

**Дата:** 2026-07-26

## Результаты уточнения

- Бот — **отдельный MAX-бот** со своим токеном, но в том же репозитории и на том же сервере.
- Рецепты по ссылке — **автопарсинг** + ручная дозапись, если сайт не отдал данные.

- Деплой — **текущий проект** (Render / Beget / VPS).

## Что делаем

Отдельный MAX-бот, который ведёт личную книгу рецептов для каждого пользователя.

Пользователь присылает ссылку на рецепт — бот вытаскивает:
- название блюда,
- ингредиенты,
- шаги приготовления,
- фото,
- ссылку на источник.

Сохраняет в личную коллекцию. В меню — кнопки: «Мои рецепты», «Поиск», «Добавить вручную», «Редактировать», «Список покупок».

## Почему так

- МАКС API умеет кнопки, текст, фото — хватает для MVP.
- Автопарсинг схемы `schema.org/Recipe` работает на многих кулинарных сайтах (eda.ru, povar.ru и др.).
- Если сайт не отдаёт структуру, ручное добавление спасает ситуацию.
- SQLite уже используется в проекте — проще расширить текущую базу, чем поднимать новую.

## Таблицы в SQLite

```sql
CREATE TABLE IF NOT EXISTS recipes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  title TEXT NOT NULL,
  source_url TEXT,
  image_url TEXT,
  image_path TEXT,
  ingredients TEXT,
  instructions TEXT,
  portions TEXT,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP,
  updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_recipes_user ON recipes(user_id);
CREATE INDEX IF NOT EXISTS idx_recipes_title ON recipes(title);
```

## Функции бота

### Главное меню
Кнопки:
- 📚 Мои рецепты
- ➕ Добавить по ссылке
- ✍️ Добавить вручную
- 🔍 Поиск
- 🛒 Список покупок

### Добавление по ссылке
1. Пользователь присылает URL.
2. Бот парсит страницу.
3. Показывает превью: фото, название, ингредиенты, шаги.
4. Кнопки: «Сохранить», «Редактировать перед сохранением», «Отмена».
5. Если распарсить не удалось — бот честно пишет и предлагает добавить вручную.

### Добавление вручную
Пошаговый сценарий:
1. Название.
2. Ингредиенты (списком).
3. Способ приготовления.
4. Порции (опционально).
5. Ссылка на источник (опционально).
6. Фото (можно пропустить).

### Мои рецепты
- Пагинированный список (по 5–7 рецептов).
- Нажатие открывает карточку: фото, ингредиенты, шаги, ссылка на источник.
- В карточке кнопки: «Редактировать», «Удалить», «Список покупок», «Назад к списку».

### Поиск
- Подменю: «По названию» / «По ингредиенту».
- Пользователь вводит запрос.
- Бот ищет LIKE по соответствующему полю и показывает результаты.

### Редактирование
- Выбор поля: название, ингредиенты, шаги, порции, ссылка, фото.
- Бот просит новое значение и сохраняет.

### Список покупок
- Пользователь выбирает рецепт.
- Бот отправляет список ингредиентов в формате:
  ```
  🛒 Список покупок: Название рецепта
  [ ] яйца — 3 шт.
  [ ] мука — 200 г
  ...
  Источник: ссылка
  ```

### КБЖУ
В первой версии не реализуем. Оставляем поле `portions` как задел на будущее.

## Риски и ограничения

- Автопарсинг зависит от разметки сайта. Сайты без `schema.org/Recipe` отдадут только название и фото.
- Некоторые сайты блокируют запросы с серверов (Cloudflare). В таких случаях — ручное добавление.
- Длинные рецепты могут превысить лимит сообщения МАКС; будем разбивать на несколько частей.
- Фото передаются через загрузку на сервер МАКС; большие файлы могут не пройти.
