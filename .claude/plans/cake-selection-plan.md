# План: добавить выбор вида торта с фото

**Дата:** 2026-07-03

## Что делаем

В сценарии заказа после выбора продукта «Торт» клиент видит алфавитный список видов тортов. При нажатии на название бот присылает фото этого торта с кнопками «Выбрать этот торт» и «Назад к списку». После подтверждения — переход к выбору даты.

## Почему именно так с фото

Telegram не умеет показывать фото внутри inline-списка. Ближайший удобный вариант: список названий → нажатие → фото + подтверждение. Это не шлёт 10 фото сразу и даёт клиенту увидеть именно тот торт, который выбрал.

## Файлы, которые меняем

1. `src/config/index.js` — добавить константу `CAKE_TYPES` (названия в алфавитном порядке + путь к фото).
2. `src/utils/keyboard.js` — добавить `cakeTypeKeyboard()` для списка видов тортов.
3. `src/bot/telegram/scenes/newOrder.js` — новые шаги: `cake_type` (выбор вида), `cake_confirm` (фото + подтверждение). Обработка callback `cake_` и `cake_confirm_`.
4. `src/services/orderService.js` — не трогаем, продолжаем сохранять `product_name` как выбранный вид торта.
5. Создать папку `uploads/cake-photos/` для фото видов тортов (пока пустая).

## Пример структуры фото

```js
const CAKE_TYPES = [
  { name: 'Ваниль-клубника', photoFile: 'uploads/cake-photos/vanil-klubnika.jpg' },
  { name: 'Вишня-шоколад', photoFile: 'uploads/cake-photos/vishnya-shokolad.jpg' },
  // ...
];
```

Фото пока не загружены, поэтому бот будет показывать текст "Фото этого торта пока не добавлено" с кнопкой подтверждения. Когда пришлёшь фото — просто заменим файлы в папке.

## Новый сценарий заказа

1. `/start` → меню.
2. «Записаться» → ввод имени.
3. Ввод имени → выбор продукта из каталога.
4. Выбор «Торт» → список видов тортов (алфавитный).
5. Выбор вида → фото + кнопки «Выбрать этот торт / Назад к списку».
6. Подтверждение → выбор даты.
7. Дальше как сейчас: время, доставка/самовывоз, телефон, комментарий, фото-примеры, предпросмотр.

## Что остаётся без изменений

- Календарь, время, доставка, адрес, телефон, комментарий, фото-примеры к заказу.
- Админка и перенос заказа.
- Продукты «Пряники», «Зефир» и т.д. — при их выборе переход сразу к дате, как сейчас.

## Проверка после правок

- Запуск бота локально.
- Полный сценарий: /start → Записаться → имя → Торт → выбор вида → фото/подтверждение → дата → время → самовывоз → телефон → комментарий → Готово → предпросмотр.
- Проверка, что при выборе другого продукта (не торт) всё работает по старому.
