# Книга рецептов — MAX-бот

Персональная кулинарная книга прямо в Мессенджере MAX.

Пользователь присылает ссылку на рецепт — бот вытаскивает название, ингредиенты, шаги, фото и источник. Всё сохраняется в личную коллекцию.

## Возможности

- 📚 **Мои рецепты** — пагинированный список.
- ➕ **Добавить по ссылке** — автопарсинг с сайтов.
- ✍️ **Добавить вручную** — пошаговый ввод.
- 🔍 **Поиск** — по названию или ингредиенту.
- ✏️ **Редактировать** — любое поле.
- 🗑 **Удалить** — с подтверждением.
- 🛒 **Список покупок** — по выбранному рецепту.
- 🔗 **Ссылка на источник** — всегда под рукой.

## Стек

- Node.js (CommonJS)
- `@maxhub/max-bot-api` — MAX-бот
- `better-sqlite3` — база данных
- `cheerio` — парсинг HTML
- `express` — healthcheck

## Запуск локально

```bash
npm install
cp .env.example .env
# добавь MAX_RECIPE_BOT_TOKEN в .env
npm start
```

Сервер поднимется на порту 3001 (или на том, что указан в `PORT`).

## Деплой

Скопируй папку `Kniga` на сервер, установи зависимости и задай переменные окружения:

```env
NODE_ENV=production
PORT=3001
MAX_RECIPE_BOT_TOKEN=токен_из_MAX
```

## База данных

SQLite создаётся автоматически в папке `data/`.
